# Plataforma de E-commerce

Projeto desenvolvido para a disciplina de desenvolvimento de software utilizando o framework Flask.

## Descrição

O sistema permite que usuários realizem anúncios e compras de produtos, além de possibilitar perguntas, respostas, favoritos e consulta de relatórios.

## Funcionalidades

- Cadastro de usuários
- Cadastro de anúncios
- Cadastro de categorias
- Perguntas sobre anúncios
- Compra de anúncios
- Lista de favoritos
- Relatório de vendas
- Relatório de compras

## Tecnologias utilizadas

- Python
- Flask
- HTML
- Jinja2

## Estrutura

O projeto utiliza o padrão de organização baseado em rotas Flask e templates HTML.
